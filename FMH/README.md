## Decompressing the archive

The decompression pipeline for reconstructing original `sourmash` `.sig` files from a compressed FracMinHash sketch database generated by our compression pipeline.
A demo compressed archive, `compressed_archive.tar.xz`, is included to demonstrate the output produced by our compression algorithm.

### Requirements

- Linux
- Bash
- Python 3
- C++17 compiler (`g++`)

cd SRA-sketches-database/FMH
mkdir build && cd build

### Decompression

```bash
./decompression_pipeline.sh <compressed_archive.tar.xz> <output_directory>
```

### Example

```bash
./decompression_pipeline.sh compressed_hashes.tar.xz .
```
After successful completion, the reconstructed `.sig` files and the archived `VERSION` file are retained inside the decompression directory.
```text
decompressed_sigs/
    ├── VERSION
    └── sigs/
        ├── accession_1.sig
        ├── accession_2.sig
        └── ...
```

### Archive Compatibility

The decompressor verifies the archive version before extraction. Archives generated by unsupported versions of the compression pipeline will be rejected.

## Comparing Custom Datasets Against the Database

### Generating Custom Sketches

To create a FracMinHash sketch for a dataset and compare it against the database, follow these steps:

**Installation (via Conda, recommended):**
```
conda create logan-sketches
conda activate logan-sketches
conda install -y bioconda::sourmash
```

**Sketch Generation:**
```
sourmash sketch dna -p dna,k=31,scaled=1000,abund <file_to_sketch.fa> -o sketch_file
```

## Additional Scripts

The scripts used to create compressed archives are available in:

```text
compression_scripts/
```

A toy dataset containing 15 sourmash `.sig` files is available in:

```text
toy/
```

The scripts used to validate the reconstructed signatures through unit testing are available in:

```text
test/
```

The toy dataset can be used to test the complete workflow by compressing the original signatures, decompressing the generated archive, and comparing the reconstructed signatures against the original toy signatures using the unit-testing script.
