### Overview

This archive contains a filtered pairwise similarity matrix associated with the following work:

```txt
Sketching the SRA: experiment-wide similarity search across 4.8 million metagenomes

Roland Faure, Adrita Hossain Nakshi, Md. Hasin Abrar, Teo Lemane, Mohsen Taheri, Stephanie Won, Haonan Wu, David Koslicki, and Paul Medvedev
```

For instructions on using the matrix, see the `Similarity-Matrix` folder in the [SRA Metagenome Sketches Database](https://github.com/RolandFaure/SRA-metagenome-sketches-databases) repository.
